# MNIST Classifier Comparison: Анализ моделей машинного обучения

## 📌 Описание работы
Данный исследовательская работа представляет собой сравнительный анализ пяти различных алгоритмов машинного обучения для распознавания рукописных цифр на основе набора данных MNIST. Репозиторий разработан для наглядного изучения принципов работы ML-моделей и их сравнения по ключевым параметрам.


## 🧠 Изучаемые модели

### 1. **k-NN (k-ближайших соседей)**
- **Принцип**: Классифицирует объект по большинству голосов его k ближайших соседей
- **Плюсы**: Простота, не требует обучения
- **Минусы**: Медленный при предсказании

### 2. **Полносвязная нейронная сеть**
- **Принцип**: Многослойный перцептрон
- **Плюсы**: Хорошо улавливает сложные зависимости
- **Минусы**: Требует много данных

### 3. **CNN (сверточная нейронная сеть)**
- **Принцип**: Специализирована для обработки изображений
- **Плюсы**: Лучшая точность для изображений
- **Минусы**: Сложная архитектура

## 📊 Метрики сравнения

Каждая модель оценивается по трем параметрам:

1. **Точность (Accuracy)** - процент правильных предсказаний
2. **Время обучения** - сколько секунд требуется для обучения
3. **Время предсказания** - скорость работы на новых данных
